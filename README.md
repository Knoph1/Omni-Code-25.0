## Omni-Code 25.0: The Founder's Journey 🚀

An interactive, responsive single-page web edition for ***Omni-Code 25.0: The Founder's Journey*** — a personal and technical memoir navigating full-stack software development, paramilitary rigor, tax & customs administration and building **Omni-Legacy Limited**.

---

## 📖 Overview

This repository hosts the web reader for *Omni-Code 25.0*. Designed with modern UI/UX paradigms, it offers a seamless reading experience across desktop, tablet and mobile devices with interactive code blocks, progress tracking and customizable typography.

### Features
* **Zero Dependencies:** Built with pure HTML5, vanilla JavaScript and utility-first styling via Tailwind CSS CDN.
* **Responsive Drawer & Sidebar Navigation:** Quick jumps across chapters, front matter and back matter.
* **Dark / Light Mode:** Automatic theme detection with instant manual toggle.
* **Accessibility & Reader Controls:** Real-time font-size adjustment (A-, Reset, A+) and dynamic reading progress bar.
* **Interactive Code Blocks:** Syntax-highlighted code snippets with single-click copy functionality.
* **Production-Ready Deployment:** Formatted as `index.html` for instant hosting on GitHub Pages, Vercel or Netlify.
